# Проверка формата vpn://

Текущая реализация — предварительная гипотеза из плана: 4-байтовая big-endian длина несжатого содержимого, затем zlib deflate и URL-safe Base64 без padding.

Перед production необходимо:
- получить тестовые URI, созданные официальным приложением AmneziaVPN;
- декодировать их и сравнить побайтовую структуру;
- проверить UTF-8, пустые данные, большие payload и round-trip;
- подтвердить, что приложение принимает URI, созданные этим кодом.

До выполнения этих проверок не использовать генератор для выдачи конфигураций пользователям.
